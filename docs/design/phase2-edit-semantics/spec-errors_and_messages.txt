LANGUAGE. English only. The repo has no i18n mechanism: app/layout.tsx sets lang="en" and there are no message catalogs. The only Arabic is the static maintenance page (lib/maintenance.ts). Arabic-Indic and Persian digits are accepted as input everywhere.
Messages carry field LABELS, never values. Live values travel only in STALE_FIELDS `current`, and only for fields in the actor's own patch, on branches he may edit.

SUBMIT (POST /api/forms/customer-edit → submitEditAction; the route always answers HTTP 200 with the action's shape)

FORM_OUTDATED (FormOutdatedError, 409, fields { _form })
- Sent when: v is not 2, or a checked key was sent without a base entry.
- Text: 'This page was opened before an app update, so nothing was sent. Reload the page and submit again.'
